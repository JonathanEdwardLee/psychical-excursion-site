How this book treats evidence

This is a nonfiction experiment, not a conversion manual.

Some chapters report laboratory findings. Some report history and tradition. Some report Jonathan's own experience. Those are not the same kind of claim.

The book does not require belief in literal astral projection. It also does not require disbelief. It asks for practice, records, and a willingness to keep extraordinary interpretations testable.

Where evidence is strong, the book says so. Where it is mixed or missing, the book leaves the question open.
